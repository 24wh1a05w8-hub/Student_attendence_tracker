# AttendEase - Student Attendance Tracker

A simple Flutter app (no backend, no extra packages). Data is kept in memory.

## First-time setup (run once, inside this folder)

    flutter create .
    flutter pub get

`flutter create .` adds the android / ios / web / windows platform folders.
It keeps your existing lib/main.dart and pubspec.yaml.

## Run

    flutter run

or press F5 in VS Code.

## Where things are

- lib/main.dart  -> the whole app (all screens)
- pubspec.yaml   -> project settings
